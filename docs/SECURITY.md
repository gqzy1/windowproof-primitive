# Security boundaries

The transaction sender owns each record. ID namespaces, immutable input, exact integer revisions and accepted analysis hashes prevent a different wallet, stale client or altered proof from committing a schedule. Every schedule is rechecked against all accepted numeric edges; a stored FEASIBLE label alone does not authorize arbitrary times. COMMITTED is terminal.

All public prose is untrusted. It is serialized under fixed prompts, constrained to bounded schema and independently interpreted. The validator independently interprets the entire original clause set and compares every canonical rule. Accepted anchors are fixed to their complete original clauses and cannot become model-authored explanations. Source anchoring does not prove semantic truth; correlated model errors and malicious source authors remain possible. No automatic acceptance follows a source instruction, model confidence score or well-formed JSON.

A business UNKNOWN is distinct from a model failure. Failed parsing, exceptions, ungrounded anchors or disagreement must not mutate state. Unknown rules block complete analysis. Explicit contradictory rules are preserved and cannot be softened to obtain a passing schedule. The application can reveal a real inconsistency only within the supplied model, not authenticate an actual clock or event.

Numeric computation uses integer difference constraints, never floating tolerance. Domain edges bind every event. Negative-cycle witnesses are checked for continuity and negative sum; feasible extrema are checked against every edge. The independent verifier computes all shortest paths using a separate algorithm. Tests compare against all integer schedules for 700 bounded random constraint sets, including impossible intervals and horizon conflicts.

No payable entry point, asset transfer, external command, HTTP request, administrator bypass or frontend is present. Declaration text is public and should exclude secrets. The protocol does not guarantee scheduler liveness, exact wall-clock timing or real-world event completion.
